データの取り扱い

本診断は、回答途中の中断・再開のため、選択履歴と診断状態をブラウザの localStorage に保存します。

外部送信

site-config.js の collectDiagnostics が true かつ dataEndpoint が設定されている場合に限り、Scene・表示選択肢・選択内容・診断結果・技術バージョンを送信します。初期状態では外部送信は無効です。

収集しない情報

氏名、メールアドレス、SNSアカウント、自由記述、正確な住所は診断ログへ含めません。

削除

トップ画面または結果画面の「保存データを削除」から、ブラウザ内の診断データを削除できます。

任意アンケート

CoC・PL・KP・シナリオ制作経験は、結果表示後に任意で回答できます。回答しなくても診断結果や共有機能は利用できます。
